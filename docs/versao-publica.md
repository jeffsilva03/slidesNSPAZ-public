# Sobre esta versão pública

`slidesNSPAZ-public` é uma cópia independente para portfólio, criada em 02/11/2026 a partir dos arquivos revisados do projeto. Não é um fork e não contém o histórico Git anterior.

- Inclui o código, README, assets necessários e exemplos revisados.
- Não inclui banco pessoal, credenciais, arquivos locais ignorados, uploads ou mídias retiradas durante a revisão.
- O repositório usado pela aplicação em produção continua privado e separado. Nenhum deploy, domínio, banco, integração de hospedagem ou branch principal de produção foi modificado para criar esta cópia.
- Esta cópia pública não recebe atualizações automáticas da produção. Futuras atualizações devem passar novamente por revisão de dados antes da publicação.
- Para executar, siga o README e configure suas próprias variáveis e serviços de teste. Os arquivos de hospedagem são exemplos; não conectam esta cópia à aplicação existente.

Os limites de segurança e de validação do código estão em [Auditoria](./auditoria-portfolio.md) e [Validação](./validacao-readme.md). Publicar o código não certifica o aplicativo para produção.
